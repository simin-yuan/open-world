# 09 · 人手扫捕，会在自己的战报里把猎物写第二遍

**观测**（本机可重跑；原始输出存档在本机 `EXCURSION_10H/evidence/t9_*`，不进本仓）

| 事实 | 怎么得的 |
|---|---|
| `findings/08` 第 68、75 行含操作者名字**字面**（小写形态） | `git grep -n -i <操作者名>` → 命中 2 行 |
| 该提交 `98fc0ee` 领先 `origin/main` **5 个提交** | `git rev-list --left-right --count origin/main...HEAD` |
| `origin/main` 上**没有**该字面 | `git grep -c -i <操作者名> origin/main` → 无命中（rc=1） |
| 导出 job `20 9,21 * * *` 会把本地领先的**所有**提交一并推走 | cron 台账（见 `findings/08` 附带观测） |
| 新闸第一次跑就报出它 | `python verify/leakscan.py` → `LEAK findings/08…: L2-term -> '<名字>'`，**rc=1** |

**形状**：R10 的战报里写着「公开仓扫一遍，命中两处（`git grep -n -E '<模式>'`）」—— 而那个**模式串本身**
含操作者名字。写「我扫过什么」的时候把**扫描模式**逐字抄进战报，就等于在这份**修泄漏**的文档里
把同一个泄漏写下第二遍。人手扫捕的盲区不是「没扫」，是**扫的对象**：它扫的是别人的产物，
写修法的这份文档自己**没被再扫一次**。

这与本仓已记的两条同族：`判据测的范围 ≠ 它宣称的范围`（08）、`对照跟着被测对象一起沉`（07）。
三次都不是「没验」，是**验的东西和宣称的东西不是同一个**。

**闸怎么做的**（`verify/leakscan.py` + `verify/selftest_leakscan.py`）

- **L1 形状层**：盘符绝对路径 / 网络（UNC）路径 / 用户配置内部路径。跑在**整个工作树**上，
  不看 git 追踪状态 —— 未 `add` 的新文件同样在扫描范围内。
- **L2 字面层**：操作者私有标识串（真名 / 私有状态树名 / 主机名 / 机构名），词表在
  `_local/privterms.txt`，随 `_local/` 一起被 `.gitignore` 排除。**词表不提交** ——
  提交它等于把要挡的词自己公开一次，逻辑上自毁。
- **豁免逐条写理由**（脚本里的 `ALLOW` 表，`--explain` 会连理由一起打印）。
  无理由的豁免就是真泄漏的长期白名单，所以数据结构上不允许「不写理由的通过」。
- 退出码 `PASS=0 / FAIL=1 / UNDECIDABLE=2 / ERROR=3`，**FAIL 优先于 UNDECIDABLE**；
  词表读不到时报 2，不猜成 0 —— 不让「没查」和「干净」长得一样。

**它测什么、不测什么**（照本仓纪律，先划边界）

| 层 | 覆盖 | **不覆盖** |
|---|---|---|
| L1 形状 | 机器生成的绝对路径 / 网络路径 / 用户配置路径；URL 的协议分隔**不误报**（有专门对照用例） | 合成占位路径与真路径**同形**（只能靠 `ALLOW` 逐条豁免）；图片/二进制里嵌的信息 |
| L2 字面 | 词表写明的标识串（大小写不敏感、按词边界匹配） | 语义换写法（同音、拼音、缩写、拆分拼接）；**CI 完全覆盖不到**（干净 clone 上没有 `_local/`） |

**CI 只跑形状层**（`--shape-only`，输出里**强制打印「L2 未跑」**）：这是**缩小的范围**，
不是静默的通过。要让 CI 也覆盖字面层，得把词表放进 GitHub Actions secret ——
**那是对外配置变更，归授权人判，本线不做。**

**自证会红吗**（`_t9_falsify.py`，3/3：把闸改坏，自证必须跟着红）

| 探针 | 期望 | 实测 |
|---|---|---|
| BASE 未变异 | 自证 10/10 绿 | `rc=0` |
| M1 `scan()` 强制 `rc=0`（闸恒绿） | 自证红 | `rc=1`，6 条用例 `[MISS]` |
| M2 豁免分支改成 all-allow | 自证红 | `rc=1`，H1「无豁免应红」被击穿 |

**边界**：未改 `check.py` 判据、未改任何阈值、未改导出 job（那是桥，不是本仓的东西）；
未加域名、未花钱、未注册平台、**未推远程**（推送 = 对外发布，须授权人批）。
本轮修的是**正文里的一处字面**、加的是**检查**；判据不归本线。

**留给授权人的口子**（本线不做）：① 词表进 CI 需要 secret；② 词表覆盖不到的口子
（拼音 / 缩写 / 语义换写 / 图片内文字）目前**没有**机器判据 —— 那是**未知**，不写成「没有」。
