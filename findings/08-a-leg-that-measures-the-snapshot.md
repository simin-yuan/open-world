# 08 · 采集腿量的是「快照的年龄」，不是「采样器活着」

**观测**（本机可重跑；原始输出存档在本机 `EXCURSION_10H/evidence/`，不进本仓）

| 对象 | 事实 | 怎么得的 |
|---|---|---|
| live 采样台账（采集侧源文件） | mtime = 2026-09-29 07:10，末条 `read_at=2026-09-29T07:10:23+08:00` | `ls` / `tail` |
| 采样驱动 cron | 表达式 `10,40 * * * *`，last_run `2026-09-29T07:10:25`，last_status `ok` | cron 台账 |
| 导出驱动 cron | 表达式 `20 9,21 * * *`（**每 12 小时**），last_run `2026-09-28T21:20:18` | cron 台账 |
| 本仓快照 `data/EXPORT_STATE.json` | `exported_at=2026-09-28T21:20:14`，`newest.state_read=2026-09-28T21:10:16` | 仓内文件 |
| `verify/check.py` 跑在快照上 | `[采集腿] … 10.5h 前（硬线 6h）` **FAIL** | 本机实跑 |

**判据测什么**：采集腿算 `h = now − reads[-1].read_at`，硬线 6h；而 `reads` 取自**本仓里那份快照**
（CI 在别处 checkout 到的那个），不是 live 采集源。于是

```
h = now − (上次导出时刻 − ≤0.5h)          # 由导出节奏封顶，与采样器是否活着无关
```

**根因**：导出每 12h 一次 ⇒ 快照里 newest read 的年龄在 `0→12h` 之间锯齿；硬线 6h ⇒
**每次导出后约 6h 起转红，直到下次导出**。这是**结构性假红**：采样器完全健康时也红。
它与「采样器真的停过 55h」那次在输出上**同形**，肉眼分不出来。

**推翻了什么**（显式划掉，不静默改口）：`findings/07` 与任务队列的 R9 段把三条 FAIL 的因写成
「**live 台账数据陈旧**」（07 原文：「这三条说的是 live 台账数据陈旧」）。**该归因不准**：

- 对 **决策腿 / 批次** 成立（live 的决策台账确实停在 `09-27 20:05`、预测停在 `09-22`）；
- 对 **采集腿** 不成立：live 采集台账 `07:10` 还在写。采集腿红的是**快照年龄**，不是采集源陈旧。

作废的是「三条同因」这句；观测本身（三条都红）不变。R9 的其余部分仍有效。

**仍是真的（归另线，本仓不处置）**

- 决策腿 `35.5h`：预测/决策写入腿停着（cron 台账里没有引用出题脚本的 job）——真停摆。
- 批次 `09-27 due=4 answered=0`（当次 `READ_FAILED: ERR 1`）——真漏答；且这条腿**结构上会永久红**：
  任一历史批次漏过一行，重扫必命中，永不恢复。这是同一份记录里**第二处**「判据测的范围 ≠ 它宣称的范围」。

**未证实**（写成未知，不写成「没有」）：公开 CI 侧的真实红绿序列未取（本机看不到 Actions 历史）。
仅按 CI `0 */6 * * *`（约北京 02/08/14/20）与 `09:20/21:20` 导出交错**推演**：约一半运行会因采集腿转红。
**推演，非实测。**

**建议（不归本仓做；改判据/阈值 = 改公开判据，须授权人署名）**

1. 采集腿改**导出相对**口径：`exported_at − newest.read_at ≤ ~1h`（问「导出那一刻采样器活着吗」），
   把「快照年龄」交给导出腿（它已 ≤36h）。
2. 或把导出节奏提到 ≤6h。
3. 批次腿只判最近 N 天，不判全历史。

**边界**：本仓**未改 check.py 判据、未改任何阈值、未改导出节奏**（判据不归我；被测对象不得自拟判据）。
本轮只记录 + 取证。

## 附带观测（未处置，交授权人判）

本仓实测是**公开**仓库（未认证访问返回 200 且 `"private": false`）。导出 job 每次运行会
`git add -A` → commit → `git push origin main`，把本地领先 origin 的**所有**提交一并推出去（不止 data）。
因此本仓各轮写的「未推远程」只成立于两次导出之间（≤12h）。本轮把两处会在公开仓暴露本机路径/人名的
正文修掉（见下），**未改导出 job 本身**（那是桥，不是本仓的东西）。
